## Problem
사용자 선호를 단일 가중치 점수로만 모델링하면 "중요도"와 "확신/반복성"이 한 값에 섞인다. → "한 번 말했지만 절대적으로 중요한" 선호와 "여러 번 나왔지만 사소한" 선호가 구분되지 않는다.

## Solution
두 개념을 별도 필드로 분리하되 축은 늘리지 않았다(사용자의 단순함 선호 존중):
- **중요도** = 범주(필수/중요/선호/실험) + 0–100 점수
- **성숙도/확신** = 상태(provisional → established), 반복·검토로 승격
추가로 규칙에 `유형`(선호/금지/표기), 캡처 시 일회성/상시 분류로 오염 방지, 전체 취향은 「선호 프로파일(자화상)」 요약으로 일반화 판단.

## Key Insight
학습된 선호를 모델링할 때 *가치(중요도)* 와 *증거(확신/반복)* 를 분리하라. 새 축을 추가하기 전에 기존 상태 필드(provisional/established)로 확신을 표현할 수 있다.
