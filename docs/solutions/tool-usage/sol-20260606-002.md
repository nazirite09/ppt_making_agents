## Problem
디자인 시스템의 정확한 토큰 값(hex·타입스케일 등)을 **추측 없이** 얻어야 했는데, 일반 경로가 다 막혔다: 문서 사이트는 SPA라 WebFetch가 토큰 표를 못 가져오고, npm 웹페이지(npmjs.com)는 봇에 **403**, 대상 GitHub repo는 **404**(비공개/이름 다름), Playwright는 `file:` 프로토콜 차단.

## Solution
소스에서 직접 떴다:
- **라이선스·메타데이터:** npm **레지스트리 API** `https://registry.npmjs.org/<pkg>` (열린 JSON, 403 안 걸림) → `license`, `repository`, 최신 버전, 설명.
- **패키지 파일(LICENSE.md, 토큰 CSS 등):** **jsDelivr** `https://cdn.jsdelivr.net/npm/<pkg>/<path>` 로 원문 직접 fetch.
- **공개 repo 소스(정확한 토큰 정의 파일):** `git clone --depth 1 --filter=blob:none --no-checkout <repo>` → `git ls-tree -r --name-only HEAD | grep` 로 경로 탐색 → `git cat-file -p HEAD:<path>` 로 **개별 블롭만** 받아 정확 값 추출. 전체/대용량 체크아웃과 경로 추측 404를 회피.
- 로컬 HTML 렌더 검증은 `file:` 차단 우회로 `python -m http.server --directory <folder>` 후 `http://localhost:PORT/...`.

## Key Insight
정확한 값이 필요하면 **렌더된 문서가 아니라 소스**에서 떠라. 웹 UI가 막히면 그 뒤의 기계 친화 경로가 거의 항상 열려 있다 — 패키지는 **레지스트리 API + jsDelivr**, repo는 **부분 클론 + `git cat-file`**.
