## Problem
Figma 레퍼런스 덱에서 슬라이드 **구조**(프레임 이름·좌표·크기·텍스트)를 뽑아 형식 사양을 만들어야 한다. 사용자가 준 로컬 `.fig`는 직접 파싱이 어렵다.

## Solution
- **`.fig`는 ZIP 아카이브** = `canvas.fig`(Figma 전용 kiwi 바이너리 — 외부 스키마 없이 신뢰성 있게 디코드 불가) + `thumbnail.png`(전체 합성 1장, 보통 너무 작아 글자 못 읽음) + `meta.json` + `images/`. → 구조 추출엔 부적합.
- **정석: 라이브 Figma URL + Figma MCP.** `get_metadata`(nodeId 없이 호출=페이지 목록 → 페이지 nodeId로 프레임 트리 XML: id·이름·x/y·w/h). **텍스트 레이어의 `name`이 실제 텍스트 내용**을 담아 스크린샷 없이도 문구를 좌표째 캔다(표지·워드마크 등 아웃라인 처리된 것은 벡터라 안 잡힘 → 그건 `get_screenshot`).
- `get_metadata` 출력이 매우 크면(수십만 자) 파일로 저장됨 → **로컬에서 XML 파싱**(파이썬 ElementTree)으로 최상위 16:9 프레임·좌표·텍스트를 뽑는다.
- **MCP 호출 한도 주의**(Starter 플랜은 금방 막힘) → 스크린샷 남발 말고 저장된 메타 XML을 오프라인 마이닝. `get_screenshot` URL은 단명 → curl 저장.

## Key Insight
Figma 추출의 진실원천은 **라이브 파일(MCP)**이다. `.fig`는 thumbnail/meta/images만 주고 구조는 안 준다. **node name = 텍스트**라 메타 XML 마이닝만으로 레이아웃·문구를 복원할 수 있어 한정된 MCP 호출을 아낀다.
