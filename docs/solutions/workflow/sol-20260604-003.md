## Problem
선호 지식베이스를 빨리 채우려고 프로젝트의 기존 산출물(예: 과거 스토리보드·덱)을 시드로 쓰고 싶은 유혹이 있다.

## Solution
사용자가 명확히 했다: **검토(컨펌)를 거치지 않은 출력은 유효한 선호 신호가 아니다.** 브레인은 빈 상태로 출발하고, 규칙은 *실제 컨펌된* 피드백에서만 제안형으로 누적한다. 일회성 지시는 규칙화하지 않는다(일반화 가설을 명시해 확인).

## Key Insight
신뢰할 수 있는 선호 신호는 *확정·검토된* 결정뿐이다. 미검토 산출물은 KB 시드/가중치에서 제외해 오염을 막아라.

## Context
`knowledge/user-brain.md` 초기 시드 정책. 기존 `하나님은_누구신가_*` 산출물은 시드·검증에서 제외.
