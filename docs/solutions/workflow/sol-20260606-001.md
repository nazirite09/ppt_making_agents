## Problem
사용자가 외부 디자인 시스템(NewsKit, Nord)을 우리 visualize 덱/레퍼런스로 "그대로 재현"하길 원했다. 토큰 값(색·타입·간격)을 추출해 우리 산출물에 쓰는 것은 **기술 문제가 아니라 라이선스 문제**인데, 이를 건너뛰면 재배포·사용이 위반이 될 수 있다.

## Solution
재현 착수 **전에** 패키지/레포의 LICENSE를 읽고 판정했다:
- **NewsKit = BSD-3-Clause** (© News UK) → 출처 표기만 하면 재사용·수정 OK. 폰트도 OFL 1.1(Google Fonts) → 충실 재현 진행, 산출물에 출처 한 줄 표기.
- **Nord = 독점/사내 전용** (`"SEE LICENSE IN LICENSE.md"` → "limited … solely for the purpose of performing your duties for and on behalf of Nordhealth", "may not … reproduce, retransmit, disseminate"). → **재현 불가**로 결론, 토큰 값을 저장하지 않음. 대안 제시: (a) 무료 베이스 폰트(Inter·Roboto Mono)로 "Nord-inspired" 오리지널, (b) 허용 라이선스 시스템(IBM Carbon Apache-2.0 / GitHub Primer MIT 등) 재현.
- 폰트는 시스템 라이선스와 **별도로** 확인(Nord 폰트는 독점이나 베이스는 무료).

## Key Insight
"이 디자인 시스템 재현 가능?"의 답은 거의 항상 **라이선스**가 정한다. 착수 전 LICENSE(특히 `SEE LICENSE IN LICENSE.md` 같은 커스텀)를 읽어 — 허용이면 출처 표기로 진행, 독점/사내 전용이면 만들지 말고 합법적 대안으로 전환. 기술적으로 쉽다는 것이 합법이라는 뜻은 아니다.
