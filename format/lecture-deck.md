# 슬라이드 형식: `lecture-deck` (다단원 교육·강의형 덱)

> **형식(골격) 사양서.** 무엇이 *어디에* 놓이고 무엇이 *반복*되는지를 정한다.
> **디자인은 범위 밖** — 색·폰트·일러스트·장식·톤은 `design.md`/visualize가 정한다. 이 문서는 빈 골격만 규정한다.
> **네이티브 베이스 `1920×1080`.** 좌표는 이 기준 px(레이아웃 앵커) — 렌더·감수 모두 이 크기로, 다른 아트보드 크기는 비례 환산.
> 레퍼런스: Figma "피그마 튜터 / 클로드 코드 & 피그마로 일관된 디자인 하는 방법"(커뮤니티), 59장 16:9.

이 형식은 **여러 단원으로 나뉘는 교육·강의·연속 세션형 덱**에 쓴다(단원 = 강·대지·세션·주제 등 — 소비자가 정의). 예: 주제 강의, 연속 세미나, 교리 N강 복습.

---

## 0. 3층 중 '형식'층

| 층 | 정하는 것 | 담당 |
|---|---|---|
| 내용 | 무엇을 말하나 | 콘텐츠 저작(소비자) |
| **형식 ← 이 문서** | **유형·위치·반복·순서** | 이 사양서 |
| 디자인 | 어떻게 보이나(색·폰트·이미지) | design.md / visualize |

px 값은 **레이아웃 앵커**지 디자인 토큰이 아니다. 폰트 크기·색은 디자인이 정하되, **요소의 자리와 반복 규칙은 이 문서를 따른다.**

---

## 1. 전역 고정요소 (chrome — 매 슬라이드 반복)

- **식별 마크** — 우상단 ≈`(1740, 80)`. 레퍼런스="피그마 튜터" 워드마크. 덱의 **식별마크 슬롯**(시리즈·주최·브랜드 — 텍스트 또는 로고). 콘텐츠 없으면 비워도 됨.
- **페이지 번호** — 우하단 ≈`(1820, 1010)`, 작게·저대비. 형식 `N` 또는 `N / 총장수`. **표지 제외, 그 외 전 슬라이드.** *(추가 결정 반영. 위치·형식은 기본값 — 바꿔도 됨)*
- **안전 여백** — 좌·상 `80px`. 모든 정렬의 기준선.

---

## 2. 덱 골격 (슬라이드 순서)

```
표지 → 목표(1회) → 아젠다 → [ 단원구분(Part N) + 번호본문 ×N ] × 단원수 → 마무리
```

- **목표 슬라이드는 덱 전체에 1회**(아젠다 앞). 단원별 반복 없음.
- 각 단원은 **단원구분 슬라이드로 시작**하고, 이어서 그 단원의 번호본문들.
- **단원 = 소비자가 정의**(강·대지·세션·주제 등). 예: 6강 복습 → 6단원, Part 1~6.

**필수/선택 슬롯** (감수 게이트 기준):
- **필수:** 표지(1) · 단원마다 `단원구분`+`번호본문`(≥1) · 마무리(1).
- **선택:** 목표(있으면 덱당 1회) · 아젠다(있으면 1). 짧은 덱·도입 압축 시 생략·병합 가능.

## 3. 슬라이드 유형별 골격

### 3.1 표지 (Cover) — 1장
```
┌───────────────────────────────────────────────┐
│                                    [식별마크]    │
│                                                 │
│   큰 제목                                        │
│   (좌측·다행)             [일러스트/이미지        │
│   부제                        · 선택 · 우측]      │
│                                                 │
│   일시 / 메타                                    │
└───────────────────────────────────────────────┘
풀블리드 배경 · 헤더/페이지번호 없음
```
- 제목 블록 좌측, 부제 그 아래, 일시·메타 좌하단, 식별마크 우상단, (선택) 일러스트 우측.

### 3.2 목표 (Goal) — 덱당 1회
- **중앙 정렬 단문 선언** — 이 덱/수업의 목표 한 문장. (레퍼런스: "…완성해보는 것을 목표로 합니다!")
- 식별마크 우상단, 페이지번호 우하단.

### 3.3 아젠다 (Agenda) — 1장
- 상단 **중앙** 제목 + 부제.
- 아래 **N단계(2~4) 컬럼**: 각 컬럼 = 라벨 + 설명. (레퍼런스: 3단계 가로 배열)

### 3.4 단원 구분 (Unit Divider / Part N) — 단원마다 1장
```
┌───────────────────────────────────────────────┐
│                                    [식별마크]    │
│   ( Part N )  ← 배지(알약) ≈(180,220)            │
│   큰 단원 제목  ≈(145,308)    [일러스트·선택·우측] │
│   (좌측·다행)                                     │
│                                         [p.번호] │
└───────────────────────────────────────────────┘
풀블리드 배경 (레퍼런스: 다크 틸)
```
- **단원의 첫 장.** `Part N` 배지 + 큰 단원 제목(좌측). 식별마크 우상단, (선택) 일러스트 우측.

### 3.5 번호 본문 (Numbered Content) — 주력 유형
```
┌───────────────────────────────────────────────┐
│ 키커 = 강의/덱 제목 (고정)          [식별마크]    │ y80   ┐
│ [01]  단원 제목                                  │ y122  ┘ 헤더
│ ──────────────────────────────────────────────│
│              중앙 헤드라인  (y≈265)              │
│              (부연 캡션)                         │
│         [콘텐츠 블록: §4 에서 조합]               │
│                                         [p.번호] │
└───────────────────────────────────────────────┘
```
**헤더 해부 (좌상단, 단원 내내 동일하게 반복):**

| 요소 | 위치 | 크기 | 내용 |
|---|---|---|---|
| 키커 | `(80, 80)` | ~26px | **덱/강의 제목** — 전 단원 공통 고정 |
| 번호 | `(80, 122)` | ~56px | 단원번호 `01`,`02`… |
| 단원 제목 | `(157, 122)` | ~56px | 번호 우측, 단원명 |

**본문 영역 (y≈230~1010):** 헤드라인(`y≈265`, **가로 중앙정렬**) → (선택)캡션 → (선택)§4 블록.

### 3.6 마무리 (Closing) — 1장
- **중앙 정렬 마무리/감사 문구.** 식별마크 우상단. (페이지번호 선택)

---

## 4. 본문 콘텐츠 블록 팔레트

번호 본문(3.5)의 body에 조합하는 재사용 블록 — 레퍼런스에서 관찰됨. *형식의 '허용 블록' 목록이며, 시각화는 디자인이 한다.*

- **중앙 헤드라인** (단독)
- **헤드라인 + 부연 캡션**
- **2~3열 비교** — 원/카드 + `VS`·`+` 구분자
- **N단계 프로세스** — 가로 라벨 + 설명
- **정의형** — 좌측 헤드라인 + 설명 단락
- **프롬프트/명령 콜아웃 박스** — 폭 ~1038, 하단 `y≈720~960`, 코드·프롬프트 담음
- **카드 행** — 균등 카드 3~5

---

## 5. 불변 규칙 (요약)

1. 모든 **본문 슬라이드에 헤더**(키커+번호+단원제목) 필수.
2. **한 단원 내** 번호+단원제목 헤더는 **글자·위치 동일하게 반복.**
3. **키커(덱 제목)는 전 덱 공통 고정.**
4. 좌·상 여백 80px, **좌측 정렬 기본**. 단 **본문 헤드라인·목표·마무리·아젠다 제목은 중앙정렬**(레퍼런스 양식 그대로).
5. **페이지 번호: 표지 외 전 슬라이드 우하단.**
6. **단원 시작 = 단원구분(Part N) 슬라이드.** 목표는 덱당 1회.

## 6. 소비자 매핑 (예시)

슬롯은 **도메인 중립**이다 — 소비자(설교·행사·강의 등)가 자기 콘텐츠를 슬롯에 매핑한다. 매핑 규칙은 각 소비자(에이전트/브리프)가 보유하고, 이 사양은 **슬롯만 정의**한다.

- **공통:** 키커=덱/시리즈 제목 · 단원제목=각 단원 제목 · 식별마크=주최/시리즈 마크(없으면 빈 슬롯) · 목표=덱 도입 1회.
- **예) 설교 파이프라인:** 단원=강/대지 · 번호본문←대지·예화·봉독·적용·인용 · 표지←제목 · 단원구분←전환·구분 · 마무리←마무리. ⚠ **콘텐츠 진실성(원고 충실성)이 형식보다 우선**(형식은 빈 골격) · 예배 순서는 범위 밖.
- **예) 행사 안내:** 단원=세션/순서 · 아젠다←전체 순서표 · 번호본문←각 순서 항목 · 마무리←맺음말.

## 7. DOM 계약 (렌더 ↔ 감수)

렌더(생성자)가 부착하고 형식검증(감수자)이 질의하는 **재사용 계약** — 도메인 무관.
- 슬라이드 루트 요소: `data-fmt-slot="표지|목표|아젠다|단원구분|번호본문|마무리"`
- chrome 요소: `data-fmt="kicker|unit-no|unit-title|idmark|pagenum"`
- 검증: 슬롯별 필수 `data-fmt` **존재 + 바운딩박스 구역**(키커=좌상, idmark=우상, pagenum=우하, 헤더 y≈80~178)을 허용오차로 확인. 미부착 시 스크린샷 시각 판정으로 폴백.
