# 사용자 세컨드 브레인 — user-brain.md

> 예배 설교 PPT 파이프라인의 **모든 에이전트가 공유**하는 사용자 선호 지식베이스.
> 각 에이전트는 작업 시작 시 이 파일을 읽고, **사용자 승인 후에만** 갱신한다(제안형).
> 사용자가 직접 편집해도 된다. git으로 변경 이력이 보존된다.
> 적용 우선순위: (1) 원고 충실성[절대] > (2) 필수 > (3) 중요 > (4) 선호 > (5) 실험.
>
> **scope:** `storyline`(sermon-storyline-architect) · `design`(slide-visual-designer) · `pptx`(pptx-builder) · `global`(전 에이전트).
> 각 에이전트는 **자기 scope + global**만 적용·수정한다.
> ※ 이 브레인은 현재 `sermon-storyline-architect`에 연결되어 있으며, **`slide-visual-designer`로 확장 예정**(디자인 취향: 폰트 시스템·저작권·테마 등).

## 선호 프로파일 (자화상)

> 에이전트가 규칙·피드백에서 도출·유지하는 사용자 취향 요약(3~8문장).
> 작업 시작 시 **가장 먼저** 읽어 판단을 priming하고, 규칙이 못 다루는 새 상황은 이 프로파일로 일반화 판단한다. 규칙이 바뀌면 갱신한다.

_아직 컨펌된 데이터 없음 — 실제 검토(컨펌) 피드백이 쌓이면 채워집니다._

## 가중치 모델

- **범주(점수 = 중요도):** 필수 80–100 · 중요 55–79 · 선호 30–54 · 실험 1–29
- **상태(성숙도/확신):** provisional(검증 중) · established(반복·검토로 확립) · retired
- **신규 초기점수(신호강도):** 강함(반드시/꼭/항상/거절성 변경) = 60 · 보통 = 35 · 약함 = 20
  - 승인 시 사용자가 범주를 지정하면 그 값을 우선한다.
- **조정:** 재확인 +15(최근확인 갱신) · 위반/반대 −20(+모순 플래그)
- **감쇠:** 실험·선호만 5설교 미확인 시 stale → retired 후보. **원칙·필수는 감쇠하지 않는다.**
- 점수가 인접 범주 임계를 넘으면 범주를 자동 승격/강등한다(변경 로그 기록).
- **유형:** 선호(do) · 금지(don't = 하드 회피, 절대 위반 금지) · 표기(사실·표준, 예: 역본 통일).
